# Sign-Up Form

A lightweight Sign-Up Form built with HTML5, CSS and JavaScript that focus on client-side validations.

---

## Highlights

- Regex lookahead logic ?= & ?!
- Flexbox organization
- The Constraint Validation API to customize validation messages
- Pseudo-classes to display quick, responsive visual hints

---

## Visuals

- `✓` (Green Tick):** Appears when criteria are claered
- `✕` (Red Cross):** Safely restricted to the `:user-invalid` pseudo-class.
